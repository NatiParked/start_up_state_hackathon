## Where to Add New Code

### New Route / Page

1. Create view component: `goed/src/views/MyFeatureView.vue`
2. Register route in `goed/src/router/index.js` (add to the `routes` array)
3. If it has substantial state, create `goed/src/stores/myFeature.js`

### New Feature within Existing Product

**Founder's Navigator:**
- Components → `goed/src/components/navigator/`
- Wizard steps → `goed/src/components/navigator/steps/`
- Backend calls → `goed/src/lib/api/` (call Supabase Edge Function)
- State → extend `goed/src/stores/navigator.js`

**Utah Startup Map:**
- Components → `goed/src/components/map/`
- Filter logic → `goed/src/stores/filters.js` (client-side filtering on the 96-row dataset)
- Map interactions → `goed/src/components/map/UtahMap.vue` using `vue3-openlayers`

### New Reusable Component

- Generic (used across products) → `goed/src/components/` (root level)
- Product-specific → `goed/src/components/{navigator|map|landing}/`

### New Pinia Store

- File: `goed/src/stores/{domain}.js`
- Export pattern: `export const useXStore = defineStore('x', () => { ... })`
- Already wired: `createPinia()` is registered in `main.js`

### New Composable

- File: `goed/src/composables/useThing.js`
- Export: `export function useThing() { ... }`

### New Utility / Service

- Pure JS helper (no Vue) → `goed/src/lib/` (e.g., `supabase.js`, `api/searchResources.js`)
- Static data → `goed/src/lib/constants.js` or feature-local

### New Static Asset

- Bundled (imported in components) → `goed/src/assets/`
- Public (served as-is at root URL) → `goed/public/` (needs to be created)

### New Supabase Edge Function

- Server code → `supabase/functions/{function-name}/index.js` at **repo root** (run `supabase init` from repo root)
- Client wrapper → `goed/src/lib/api/{functionName}.js` (in the Vue app)

### New Style / Theme Update

- Global → `goed/src/styles/brand.css` (planned, will hold Tailwind directives)
- Tailwind theme tokens → `goed/tailwind.config.js` (Utah blue `#0065A4` + white)
- Component-scoped → `<style scoped>` block in the `.vue` file
